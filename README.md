# 牧濑红莉栖桌宠 · 第二版（v2.0.0）

独立的 Windows 桌面小挂件。当前九张透明立绘根据用户提供的角色截图制作，属于**待确认的原型美术**，不冒充最终定稿；生成记录见 `assets/concepts/`。程序不连接网络，也没有账号、语音或大模型功能。

![第二版待机与点击姿态对照](docs/media/v2-click-poses.png)

## 第二版更新

- 三种新点击姿态：抬手挡戳、抱臂偏头、轻捂脸颊，依次循环。
- 连续点击时双臂在胸前比叉，继续点击保持，停点约 1.2 秒后恢复待机。
- 睡眠加入固定双脚的缓慢呼吸与独立飘动、淡出的 ZZZ。
- 扩充为 60 条原创中文台词，匹配动作并避免相邻重复。
- 按实际分层待机画面校准互动图的颜色，保留透明边缘。

上图由实际渲染器输出，从左到右为待机、三种普通点击和连续点击姿态；灰色底用于展示透明边缘。完整变更见 [CHANGELOG.md](CHANGELOG.md)。

## 运行

适用环境：Windows 10/11，.NET Framework 4.8。从 GitHub 下载源码后先运行下方构建命令；当前本机开发版可直接双击 `dist/MakiseDesktopPet.exe`。旧 ZIP 已归档到 `releases/previous/`，未同步后续改动。请保留 exe 旁边的 `dialogues.json`、`assets/sprites` 和 `assets/layers/idle-v1`。默认不会设置开机启动，也不需要管理员权限。

首次启动出现在主屏幕右下角，角色高度 220 像素。每次普通左键点击依次显示抬手挡戳、抱臂偏头、轻捂脸颊，再从抬手挡戳循环，并显示约 5 秒的气泡；被戳表情约 650 毫秒后恢复待机。按住角色移动可拖到新位置。拖动超过 6 像素才算拖拽，松开后显示拖动台词，不触发点击台词，也不推进表情循环。3 分钟没有和桌宠互动会睡觉，点击或拖动会唤醒；睡醒时的第一次点击仍显示唤醒表情，不推进被戳表情循环。只统计桌宠自身的鼠标操作。

1. 右键角色：换一句话、调整大小（160/220/280/340 像素）、“窗口层级 → 置顶 / 置底”、隐藏到托盘、退出。置顶时显示在普通窗口前；置底时位于普通窗口后，回到桌面可再次看到和点击角色。
2. 托盘：右键选择显示/隐藏或退出；双击托盘图标也能恢复角色。
3. 1.8 秒内点击 4 次切换为胸前叉手姿态；继续点击保持该姿态，最后一次点击约 1.2 秒后恢复待机，拖动立即打断。保持期间不推进普通表情序号、不刷新气泡。特别吐槽独立保持 20 秒冷却，冷却期间仍能触发叉手姿态。当前台词不会连续重复同一句。

隐藏后程序仍在托盘运行；选择“退出”才会结束进程。程序只在桌面上显示角色和小气泡，没有普通任务栏窗口。气泡自身不接收鼠标点击。

快速查看睡眠效果：退出正在运行的桌宠后，执行 `.\dist\MakiseDesktopPet.exe --preview-sleep`。该参数只让本次启动立即入睡，不保存为设置；点醒后仍按正常三分钟无互动入睡。

## 从源码构建和打包

先从托盘退出正在运行的桌宠，再在项目目录打开 PowerShell：

```powershell
.\build.ps1
.\dist\MakiseDesktopPet.exe
```

当前机器没有 .NET SDK，构建脚本使用 Windows 自带的 .NET Framework C# 编译器和系统图形库。构建脚本复制九张状态图、七张待机图层和图层清单到 dist，不会重新生成或覆盖源素材，也不会复制补画稿及预览。制作可解压运行的压缩包：

```powershell
.\package.ps1
```

打包输出到 `releases/`：`MakiseDesktopPet-Windows.zip`（可运行程序）和 `MakiseDesktopPet-Source.zip`（源码、测试、文档、构建脚本与全部原型素材）。源码包解压后先构建；运行包解压后保留目录结构，运行其中的 exe。配置保存在 `%LOCALAPPDATA%\MakiseDesktopPet\settings.json`，会保存位置、高度和窗口层级选择；显示器变化时角色会回到可见工作区。打包和运行都不需要联网。

## 换成最终角色素材

请提供下列 **9 张透明背景 RGBA PNG**，放在 `assets/sprites/` 中，文件名必须完全一致：

| 文件 | 真正的状态图切换 |
| --- | --- |
| `idle.png` | 原待机底稿，保留用于尺寸和布局参考；实际待机使用分层素材 |
| `blink.png` | 原闭眼底稿，保留用于素材参考；实际眨眼使用三档眼睛图层 |
| `poke-block.png` | 第一次点击：抬手挡戳 |
| `poke-fold.png` | 第二次点击：抱臂偏头 |
| `poke-cheek.png` | 第三次点击：轻捂脸颊 |
| `rapid.png` | 连续点击：双臂在胸前交叉成 X，持续点击时保持 |
| `drag.png` | 向右拖时使用原图（双腿朝左）；向左拖时水平镜像 |
| `sleep.png` | 低头闭眼、双手放松收在身前，不含文字；程序另绘动态 ZZZ，并配合缓慢呼吸 |
| `wake.png` | 刚醒来 |

当前原型使用 1122×1402 像素画布。正式图片也可以使用别的尺寸，但九张画布必须完全一致，人物在相同位置、大小接近，双脚尽量对齐；建议四周只留少量透明边，减少透明窗口的占位。替换素材后重新运行 `.\build.ps1`，或直接替换已解压目录中的同名 PNG。请只使用你有权使用的角色素材。

当前点击图为用户确认的新三张姿态，已替换旧表情。`assets/sprites/click-colors.json` 保存从实际分层待机画面提取的颜色基准。程序分别校准头发、外套、裤子、肤色、线条、衬衫、领带和眼睛的 RGB 色差，并在颜色之间平滑过渡，保留原有明暗细节和 alpha；不再统一压暗整张图。仅当点击图与参考待机图层的 SHA-256 指纹全部匹配时启用，不修改 PNG 文件。更换对应素材后校准自动失效；正式素材应由美术统一配色。

当前已接入第 3 步分层待机动画，使用 `assets/layers/idle-v1`：

- 窗口位置和身体底部 12%（包括鞋子）保持不动。身体呼吸周期 4.2 秒，220 像素时身体层顶部压缩量最大约 1.5 像素，随尺寸调整，最大 2 像素。头部随颈部实际位移衔接，并独立以约 6.2 秒周期、±0.38 度轻晃。
- 左右后发分别延迟约 220/340 毫秒跟随头部，并带很小的独立摆动（最大约 ±0.55/0.52 度）。重新进入待机时，摆动幅度用 240 毫秒逐渐恢复。
- 眨眼间隔随机 2.8～6.8 秒，依次经过半闭 45 毫秒、闭眼 110～170 毫秒、半闭 50 毫秒，再睁眼。约 10% 概率追加一次短间隔眨眼。眼睛与头部在缩放前合成，避免位置漂移。
- 普通点击保留三张表情循环，增加 250 毫秒的轻微收缩、回弹和恢复。连续点击不会叠加回弹幅度；拖动开始时取消回弹。
- 连续点击的叉手是独立整张状态图切换，进入时取消回弹，保持期间不反复播放收缩。它与普通三张点击图一样使用待机颜色基准校准，源 PNG 保持不变。
- 睡眠使用无文字睡姿图，每 5.6 秒完成一次轻微呼吸；220 像素下上方区域最大压缩 1 像素，随尺寸调整且最多 1.5 像素。底部 12% 包括双脚保持不变。三个灰紫色 Z 由程序独立绘制，间隔 1 秒依次出现，各自在 3.2 秒内向右上方飘动、变大并淡出，按 5.6 秒循环。睡眠画面最多每 40 毫秒更新一次（25 fps），字母保持在窗口边界内；唤醒后立即清除。
- 动作按实际经过时间计算；定时器请求间隔 16 毫秒，分层待机渲染最多每 16 毫秒更新一次，表情变化可即时更新；复用绘图缓冲。此设置不保证稳定 60 帧。

待机呼吸、头部和后发晃动使用分层图加程序变换，眨眼是三档眼睛图层切换。三种被戳表情、叉手、拖动、睡觉和唤醒使用独立状态图，普通点击保留第 1 步的平面回弹；睡眠使用无文字睡姿图加固定双脚的轻微纵向变形，ZZZ 独立绘制，没有拆分睡姿身体图层。因此这些状态之间仍可能有轮廓差异；渐进垂头和拖动松手缓动尚未实现。当前没有 Live2D、行走、攀爬和屏幕识别。

拖动时双腿朝移动方向的反方向：向左拖时朝右，向右拖时朝左。中途反向移动约 4 像素后切换，减少轻微抖动造成的来回翻转；纯上下移动沿用当前朝向。这里使用整张拖动图的水平镜像，头发与衣服也会翻转，不是单独的腿部动画；松开后恢复普通待机图。

台词保存在 `dialogues.json`，当前共有 60 条原创短句，不含其他人物名字，全部本地运行。按八类编辑，每类至少保留两句不同的非空台词：

| 分类 | 数量 | 使用场景 |
| --- | --- | --- |
| `click-block` | 8 | 抬手挡戳：被打断、轻微抗议 |
| `click-fold` | 8 | 抱臂偏头：好胜、有主见 |
| `click-cheek` | 8 | 轻捂脸颊：惊讶、柔和回应 |
| `rapid` | 8 | 连续点击特别回复，保持原有 20 秒冷却 |
| `wake` | 8 | 睡醒 |
| `drag` | 8 | 拖动结束 |
| `thought` | 6 | 思考与自言自语 |
| `company` | 6 | 轻松陪伴 |

普通点击有 75% 概率选择当前表情的专属台词，25% 穿插其他话题：抬手和抱臂搭配思考类，捂脸搭配陪伴类。每组随机轮完一遍再重排，并避免相邻两次出现同一句；轮次仅保存在当前进程，重启后重新随机。右键“换一句话”在待机时选择思考或陪伴类，睡眠时先唤醒并显示睡醒类，不推进点击表情序号。台词仍由用户互动触发，不会自动弹出闲聊。修改 JSON 后重新启动程序即可读取。

### 待机分层素材（第 2/3 步）

七张图层、三档眼睛合成预览、遮挡检查、转轴说明和补画记录在 [assets/layers/idle-v1](assets/layers/idle-v1/README.md)。第 3 步已接入运行程序。更换待机角色时需同时替换这七张同画布图层，并维护 layers.json 的文件名、画布尺寸和转轴；只换 idle.png 不会改变分层待机外观。

## 实测与限制

睡眠 ZZZ 与慢呼吸已通过四种尺寸的后台像素及状态检查，详见验收记录末尾。下方第 4 步动作预览保留的是此前版本，尚未更新为新的睡眠效果。

在 Windows 11、150% 显示缩放和 .NET Framework 4.8 环境开发。早期版本做过透明窗口、实际点击/拖动、焦点、托盘和菜单检查；分层版本第 3 步另做了透明窗口回归。第 4 步为了不打扰用户使用电脑，采用后台渲染和事件检查：四种尺寸、点击表情循环、方向切换、真实三分钟入睡、气泡期限、设置及边缘布局通过；本轮没有重测真实鼠标和系统托盘操作。逐轮证据及限制见 [TESTING.md](docs/TESTING.md)。

第 4 步的 [动作节选](docs/media/motion-preview.gif) 和 [四尺寸对照](docs/media/four-sizes.png) 随源码保存，都是测试输出，不是替换素材；动画来自程序渲染帧，不是桌面录屏。完整时间线 `test-artifacts/step4/full-timeline.gif` 和原始 PNG `test-artifacts/step4/frames/` 仅本机保留，不提交 Git；可运行 `tests/run-step4.ps1`，再使用安装有 Pillow 的 Python 运行 `tests/encode-step4.py` 重新生成。日常运行无需这些测试文件。当前已停在验收阶段，没有重新打包。

只有一台显示器，拔插显示器和跨屏操作尚未实测；也尚未在另一台 Windows 机器上运行。长时间稳定性及分层动作的主观手感仍需实际使用确认。当前角色图是待确认的原型美术。
