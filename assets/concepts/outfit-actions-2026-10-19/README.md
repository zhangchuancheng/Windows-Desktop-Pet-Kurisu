# 七套换装动作模板

这些素材以 `assets/sprites/` 当前运行版为姿势参考，逐套重绘对应装扮。可在 [动作对照页](index.html) 并排查看原版与换装图。

## 对应动作

| 文件 | 画面 |
| --- | --- |
| `idle.png` | 抱臂待机 |
| `blink-half.png`、`blink.png` | 半闭眼、闭眼 |
| `poke-block.png` | 点击后抬手挡住 |
| `poke-fold.png` | 点击后抱臂鼓脸 |
| `poke-cheek.png` | 点击后托腮 |
| `rapid.png` | 连点时双臂交叉 |
| `sleep.png` | 闭眼打盹 |
| `wake.png` | 从打盹回到待机的单张过渡 |
| `drag-base.png`、`drag.png` | 拖拽悬垂底稿及其相同副本 |

原版造型的呼吸、追视、点击回弹、拖拽形变、泪滴和睡眠 ZZZ 由程序绘制。换装保留基础待机微动与对应姿态图，暂不启用原版的局部眼睛追视及动态拖拽形变；旧版 52 帧唤醒序列已不在当前运行流程中。

## 文件组织

- 每个完成的装扮目录根部有 11 张 1024×1402 透明 PNG，可与当前资源文件名逐项对照。
- 生成原图与历史变体保存在本地制作目录，不属于发布源码；构建程序只需各套目录顶层的 11 张运行图。
- 制作阶段使用 `tools/export-outfit-action-set.ps1` 将生成图导出到运行版画布尺寸；重新执行此脚本须另行提供本地生成原图。女仆装和圣诞装的待机图曾用 `tools/align-outfit-idle.ps1` 校准位置与大小。

## 当前状态

实验服、女仆装、浴衣、圣诞装、红礼服手部修订版 `red-dress-handfix/`、战斗装和运动泳装 `beachwear-v2/` 均有全套动作模板。红礼服的挡手动作已重画横胸手臂，发布源码仅保留修订版；运动泳装采用白色短袖上衣、浅紫色大腿中段泳裤与小幅露腰设计。

这些动作图不覆盖原版 `assets/sprites/`。v3.0.0 的设置面板和托盘菜单可以选择七套换装，构建时会把各套顶层 PNG 复制到 `dist/assets/outfits/`。各套眨眼图在眼部以外也存在差异，部分装扮切换表情时会有轮廓跳动；眼坐标与拖拽柔性区尚未逐套校准，因此换装不使用原版的局部追视与动态拖拽形变。当前实机检查不等于所有动作细节都已修正。

各套的静态检查结果见 [QA 报告](QA-REPORT.md)，目视问题与处理优先级见 [换装审阅记录](REVIEW-NOTES.md)。
