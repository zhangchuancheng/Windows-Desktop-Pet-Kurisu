# 换装动作目视审阅

2026-10-19 对各套动作图与现行原版姿势逐张对照。这里记录绘画连贯性问题；像素格式与眨眼差异数值见 [QA 报告](QA-REPORT.md)。七套现已接入 v3.0.0 换装菜单，下面仍保留未解决的画面问题；程序可切换不代表每张动作都已完成美术验收。

| 装扮 | 主要发现 | 处理建议 |
| --- | --- | --- |
| 红礼服 | 最初旧稿的交叉手臂合成肤色横带；第一轮修订后，画面右侧手又像贴在荷叶边上的抓手，其他动作也有手指粘连。 | 已按用户选定的抱臂图修订 `red-dress-handfix/`，并再次重画挡手图的横胸手臂；修订图已用于预览与运行。其他手部细节仍需目视复核，两张眨眼帧仍有眼外像素变化。 |
| 圣诞装 | 眨眼时头部、帽子和整体轮廓下移并缩小，闭眼帧顶部相对待机下移约 27 像素。 | 优先固定待机身体与帽子，只改眼睑；再检查所有动作的站位。 |
| 浴衣 | 两张眨眼图连袖口、腰带、裙纹和发丝也被重画，切帧易闪。 | 以同一待机身体制作表情帧，保留衣纹与发丝。 |
| 实验服 | 眨眼图的头发、交叉袖口、衣摆和鞋与待机不一致。 | 优先统一表情帧以外的轮廓，随后检查袖口遮挡关系。 |
| 战斗装 | 眨眼图的护手、腰甲和头发位置变化明显。 | 固定盔甲和头发，只替换眼睑。 |
| 女仆装 | 待机和抱臂动作的手部遮挡关系仍不够明确；眨眼时头饰、围裙和鞋也变化。 | 先理顺交叉手臂的前后层次，再统一表情帧。 |
| 运动泳装 | 整套动作可辨；拖拽图的短裤比待机明显变长，鞋位置也上移。 | 统一拖拽与待机的短裤长度及鞋型，再做运行时拖拽测试。 |

优先级：先处理会在普通待机循环中频繁出现的圣诞装、浴衣、实验服、战斗装和女仆装眨眼差异；运动泳装拖拽服装一致性次之。数值检查只提示风险，最终仍需在桌宠中观察切帧和静态拖拽姿态。七套换装暂不启用原版的局部眼睛追视与动态拖拽形变。
