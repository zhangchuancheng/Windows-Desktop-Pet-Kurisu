# 角色状态图生成记录

## 初版记录（保留）

六张运行素材位于 `assets/sprites/`。待机主图由用户提供的桌宠截图作为视觉参考生成；截图中的黄色背景没有进入运行素材。生成方式为本地参考图驱动的图像生成，状态图均以 `kurisu-idle-v2.png` 为编辑输入，开启透明背景。没有从网络下载角色图。

主图的完整提示词见 `kurisu-idle-v2.prompt.txt`。下表记录了每张状态图的编辑要求；所有状态图都要求保持角色身份、服装、画布、位置、线条和透明度，且不得添加背景、文字或裁切人物。

| 文件 | 编辑要求 |
| --- | --- |
| `blink.png` | 将双眼改为自然闭合的弧线；眉毛、嘴、头部角度与身体不变。 |
| `poke.png` | 只改面部：略吃惊、轻微脸红、皱眉和小小的不满表情。 |
| `drag.png` | 双臂略微外展，小手从袖口露出，腿轻微倾斜，表情略吃惊；不得出现空袖口和动作符号。 |
| `sleep.png` | 站立打瞌睡，双眼闭合，肩膀略放松，头略偏。 |
| `wake.png` | 刚醒来的半睁眼、小张口，保留原站姿。 |

这些图是根据参考图做的**可运行原型美术**，还不是用户确认的最终角色素材。六张 PNG 均为 1122×1402 RGBA，程序运行时等比缩放到所选高度。
