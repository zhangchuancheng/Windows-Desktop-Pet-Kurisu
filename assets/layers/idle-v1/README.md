# 待机分层素材 v1

第 2 步制作的图层，2026-10-15 已在第 3 步接入桌宠程序，用于待机和眨眼。原整张状态图继续负责点击、拖动、睡觉和唤醒。

## 文件

所有正式图层均为 1122×1402、带 alpha 的 PNG；坐标与原待机图一致，请勿分别裁切或自动居中。

| 文件 | 内容 |
| --- | --- |
| hair-back-left.png | 画面左侧后发，含隐藏发根和中间重叠区 |
| hair-back-right.png | 画面右侧后发，含隐藏发根和中间重叠区 |
| body.png | 外套、衬衫、领带、身体、双腿、鞋及补全的颈部/肩部 |
| head-base.png | 去除眼睛的头部底层，保留眉毛、嘴、脸颊、刘海和前侧发束 |
| eyes-open.png | 从原待机图提取的睁眼局部 |
| eyes-half.png | 从 imagegen 补画稿提取的半闭眼局部 |
| eyes-closed.png | 从原 blink.png 提取的闭眼局部 |

眼睛图层含少量羽化的肤色边缘；它们是三选一的完整局部替换，不能同时叠加。运行程序先把对应眼睛与头部合成再缩放，两者使用同一变换。运行转轴和文件清单来自 layers.json；动作幅度与周期位于 src/LayeredIdleAnimation.cs，可在后续体验后微调。

待机追视使用 `layers.json` 的 `gaze` 坐标：两只眼的中心、椭圆半径和最大纹理偏移均按 1122×1402 原画布像素记录。椭圆仅覆盖虹膜附近，避免拉动上眼睑、眉毛和侧发；边缘的纹理位移平滑收至零。头部与后发另做小幅平滑转动。眨眼半闭时追视幅度减小，闭眼时不移动眼部。替换分层角色时请重新量出这组眼睛坐标。没有新增或下载角色素材。

## 制作方式与边界

以同一张 idle.png 为底稿。使用内置 image_gen 生成身体遮挡补全、后发遮挡补全、去眼睛的面部底稿和半闭眼稿；完整提示词及生成稿保存在 sources/，没有下载外部素材。其后通过 tools/ExtractIdleLayers.cs 按可复现的轮廓蒙版提取、对齐和合成，优先保留原图可见像素。sources/mask-head.png 和 mask-eyes.png 可用于检查分区。

这是一套从平面图制作的可编辑分层 PNG，不是原作者分层原稿，也不是 Live2D 模型。补画区域及抗锯齿边缘并不保证与旧整张立绘逐像素相同；大幅偏转超出本轮检查范围。前发仍随头部一起移动，身体和双腿仍是同一层。点击、拖动、睡眠等独立状态尚未分层。

第 2 步修正了偏转时发根的平直切口和后发中的外套边缘残留。第 3 步使用比静态检查更小的摆动幅度，检查了四种尺寸下的运行渲染和状态衔接；主观自然程度等待用户体验，完整录屏及长期运行验收留待第 4 步。

## 重建派生图片

在项目根目录运行 tools/prepare-idle-layers.ps1。它从此目录 sources/ 的保留稿重新生成七张图层、蒙版及预览，会覆盖本目录中的这些派生产物；不会改动 assets/sprites、src 或 dist。若手工精修了派生 PNG，请先另存版本再重建。
