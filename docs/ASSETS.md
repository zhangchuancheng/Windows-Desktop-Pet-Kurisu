# 素材、动画与台词替换


请提供下列 **9 张透明背景 RGBA PNG**，放在 `assets/sprites/` 中，文件名必须完全一致：

| 文件 | 真正的状态图切换 |
| --- | --- |
| `idle.png` | 原待机底稿，保留用于尺寸和布局参考；实际待机使用分层素材 |
| `blink.png` | 原闭眼底稿，保留用于素材参考；实际眨眼使用三档眼睛图层 |
| `poke-block.png` | 第一次点击：抬手挡戳 |
| `poke-fold.png` | 第二次点击：抱臂嘟脸 |
| `poke-cheek.png` | 第三次点击：轻捂脸颊 |
| `rapid.png` | 连续点击：双臂在胸前交叉成 X，持续点击时保持 |
| `drag.png` | 旧拖拽底稿，保留作素材参考；实际拖拽使用独立的 `drag-base.png` |
| `sleep.png` | 低头闭眼、双手放松收在身前，不含文字；程序另绘动态 ZZZ，并配合缓慢呼吸 |
| `wake.png` | 刚醒来 |

当前原型使用 1122×1402 像素画布。正式图片也可以使用别的尺寸，但九张画布必须完全一致，人物在相同位置、大小接近，双脚尽量对齐；建议四周只留少量透明边，减少透明窗口的占位。替换素材后重新运行 `.\build.ps1`，或直接替换已解压目录中的同名 PNG。请只使用你有权使用的角色素材。

当前点击图为用户确认的新三张姿态，已替换旧表情。`assets/sprites/click-colors.json` 保存从实际分层待机画面提取的颜色基准。程序分别校准头发、外套、裤子、肤色、线条、衬衫、领带和眼睛的 RGB 色差，并在颜色之间平滑过渡，保留原有明暗细节和 alpha；不再统一压暗整张图。仅当点击图与参考待机图层的 SHA-256 指纹全部匹配时启用，不修改 PNG 文件。更换对应素材后校准自动失效；正式素材应由美术统一配色。

当前已接入分层待机动画，使用 `assets/layers/idle-v1`：

- 窗口位置和身体底部 12%（包括鞋子）保持不动。身体呼吸周期 4.2 秒，220 像素时身体层顶部压缩量最大约 1.5 像素，随尺寸调整，最大 2 像素。头部随颈部实际位移衔接，并独立以约 6.2 秒周期、±0.38 度轻晃。
- 左右后发分别延迟约 220/340 毫秒跟随头部，并带很小的独立摆动（最大约 ±0.55/0.52 度）。重新进入待机时，摆动幅度用 240 毫秒逐渐恢复。
- 眨眼间隔随机 2.8～6.8 秒，依次经过半闭 45 毫秒、闭眼 110～170 毫秒、半闭 50 毫秒，再睁眼。约 10% 概率追加一次短间隔眨眼。眼睛与头部在缩放前合成，避免位置漂移。
- 清醒待机时眼珠在眼眶内部小幅跟随鼠标，头部和后发以更慢、更小的幅度轻轻响应；闭眼、点击、拖动、睡眠和隐藏时不追视，之后平滑回正。使用 `layers.json` 的 `gaze.eyeCenters`、`gaze.eyeRadii` 和 `gaze.maxShift` 调整眼部区域与幅度；这些坐标以原图画布像素表示。追视是程序对现有眼睛纹理的局部变形，没有新增状态图，也不计入三分钟无互动计时。
- 普通点击保留三张表情循环，增加 250 毫秒的轻微收缩、回弹和恢复。连续点击不会叠加回弹幅度；拖动开始时取消回弹。
- 连续点击的叉手是独立整张状态图切换，进入时取消回弹，保持期间不反复播放收缩。它与普通三张点击图一样使用待机颜色基准校准，源 PNG 保持不变。
- 睡眠使用无文字睡姿图，每 5.6 秒完成一次轻微呼吸；220 像素下上方区域最大压缩 1 像素，随尺寸调整且最多 1.5 像素。底部 12% 包括双脚保持不变。三个灰紫色 Z 由程序独立绘制，间隔 1 秒依次出现，各自在 3.2 秒内向右上方飘动、变大并淡出，按 5.6 秒循环。睡眠画面最多每 40 毫秒更新一次（25 fps），字母保持在窗口边界内；唤醒后立即清除。
- 动作按实际经过时间计算；定时器请求间隔 16 毫秒，分层待机渲染最多每 16 毫秒更新一次，表情变化可即时更新；复用绘图缓冲。此设置不保证稳定 60 帧。

待机呼吸、头部和后发晃动使用分层图加程序变换，眨眼是三档眼睛图层切换。三种被戳表情、叉手、拖动、睡觉和唤醒使用独立状态图，普通点击保留第 1 步的平面回弹；睡眠使用无文字睡姿图加固定双脚的轻微纵向变形，ZZZ 独立绘制，没有拆分睡姿身体图层。拖动状态从一张完整底稿连续变形，不再切换整张帧图。因此这些状态之间仍可能有轮廓差异；渐进垂头和拖动松手缓动尚未实现。当前没有 Live2D、行走、攀爬和屏幕识别。

拖动时使用 `assets/sprites/drag-base.png` 这张 313×418 的完整悬垂姿态。程序根据鼠标速度对双腿、双手和两侧发梢施加连续的小幅形变，停止后以带阻尼的弹性响应回正；面部和躯干基本保持原图，避免拆件接缝。原画眼角泪光保留，滴落的小泪珠由程序另绘。左右及上下拖动使用同一底稿，不水平镜像，也不循环切换整张图；松开立即恢复分层待机并保存位置，不触发点击。窗口尺寸与待机相同。

`drag-warp.json` 指定底稿文件、画布尺寸、泪滴起点和 `placement`（相对于桌宠窗口的绘制宽高、水平偏移、顶部位置）。当前拖拽底稿的透明留白与待机图不同，`placement` 让头顶、两侧轮廓和鞋底在 100–500 像素下与待机及三张点击图对齐；替换底稿时请重新核对这些值。替换图需为透明 RGBA PNG，保持人物头身比例与位置；若四肢、发梢位置发生较大变化，需同步调整 `src/DragWarpAnimation.cs` 中六处柔性作用区域。`drag-colors.json` 独立记录待机颜色基准与底稿指纹；更换底稿后旧校准自动失效，应重新取样制作配色配置。旧 `drag-sheet.png` 和 `drag-animation.json` 仅作历史素材记录，不再由程序加载或打入运行目录。动作是单张图的程序形变，不会自行出现原十二帧的闭眼姿态。

台词保存在 `dialogues.json`，当前共有 60 条原创短句，不含其他人物名字，全部本地运行。按八类编辑，每类至少保留两句不同的非空台词：

| 分类 | 数量 | 使用场景 |
| --- | --- | --- |
| `click-block` | 8 | 抬手挡戳：被打断、轻微抗议 |
| `click-fold` | 8 | 抱臂嘟脸：好胜、有主见 |
| `click-cheek` | 8 | 轻捂脸颊：惊讶、柔和回应 |
| `rapid` | 8 | 连续点击特别回复，保持原有 20 秒冷却 |
| `wake` | 8 | 睡醒 |
| `drag` | 8 | 拖动结束 |
| `thought` | 6 | 思考与自言自语 |
| `company` | 6 | 轻松陪伴 |

普通点击有 75% 概率选择当前表情的专属台词，25% 穿插其他话题：抬手和抱臂搭配思考类，捂脸搭配陪伴类。每组随机轮完一遍再重排，并避免相邻两次出现同一句；轮次仅保存在当前进程，重启后重新随机。右键“换一句话”在待机时选择思考或陪伴类，睡眠时先唤醒并显示睡醒类，不推进点击表情序号。台词仍由用户互动触发，不会自动弹出闲聊。修改 JSON 后重新启动程序即可读取。

### 本地聊天角色设定

`chat-persona.json` 是从作者的 [SillyTavern v1.4 角色卡](https://github.com/zhangchuancheng/SillyTavern-Character-Card/blob/main/makise_kurisu_ccv2_zh.json) 提炼的桌宠短聊设定。它只包含身份、说话方式和场景边界，未复制剧情开场、整段示例对话或世界书。编辑后重新启动程序即可读取；构建时会复制到 `dist/`。不要把原角色卡的 20 KB 内容直接粘入这个文件，当前模型的上下文窗口较小。

用户在聊天窗口“偏好”里填写的称呼、回复长度及话题偏好保存在 `%LOCALAPPDATA%\MakiseDesktopPet\chat-preferences.json`，不属于仓库文件。程序只向本机 Ollama 发送这些设定与最近四轮对话；设置保存后会清空当前短对话历史。固定点击台词仍由 `dialogues.json` 单独管理。

### 待机分层素材

七张图层、三档眼睛合成预览、遮挡检查、转轴说明和补画记录在 [assets/layers/idle-v1](../assets/layers/idle-v1/README.md)。这些图层已接入运行程序。更换待机角色时需同时替换这七张同画布图层，并维护 layers.json 的文件名、画布尺寸、转轴及眼睛追视坐标；只换 idle.png 不会改变分层待机外观。


## 应用图标

图标母版位于 `assets/icons/app.png`，多尺寸 Windows 图标位于 `assets/icons/app.ico`。修改母版后运行 `tools/build-app-icon.ps1`，再执行 `build.ps1`；无需改代码。详见 [图标说明](../assets/icons/README.md)。
