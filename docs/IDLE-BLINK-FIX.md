# 换装待机眨眼抽动修复

实验服间歇抽动的原因是 `IdleMotionAnimation` 在眨眼时切换整张独立绘制的 PNG。图中的衣服、头发、鞋子与待机图并不一致；眨眼结束没有重启待机呼吸，因此本次定位到的是切图差异。

`OutfitIdleSmoke` 对当前旧素材重新统计：下半幅画布中，任一帧 alpha ≥ 128 的像素作为分母，RGBA 任一通道差值超过 16 计为明显变化。这不是抽动位移或性能指标，也与旧 QA 报告的眼区外统计口径不同。

| 服饰 | 半闭眼图身体差异 | 闭眼图身体差异 |
| --- | ---: | ---: |
| 实验服 | 42.2% | 38.4% |
| 女仆装 | 36.1% | 43.8% |
| 浴衣 | 67.3% | 62.6% |
| 圣诞装 | 32.4% | 40.9% |
| 红礼服 | 12.5% | 15.5% |
| 运动泳装 | 8.8% | 7.3% |
| 战斗装 | 53.9% | 66.3% |

七套均存在同类切图差异。修复后，待机身体始终来自各自的 `idle.png`，局部眼睑按每套 `idle-blink.json` 绘制，再经过同一套连续呼吸渲染。保留旧图片，不修改点击、睡眠等动作素材。

验证覆盖七套服饰的 100/355/500 像素尺寸，以及 0/100/1800/4200 毫秒的呼吸阶段：在同一时刻切换睁眼、半闭眼、闭眼时，眼区外像素差异为 0，重新睁眼后整帧精确还原。对照图保存在本地 `test-artifacts/outfit-idle/`，逐套检查了眼部与全身位置。此结论针对眨眼引起的抽动，不意味着所有动作切换都没有美术差异。
