牧濑红莉栖桌宠 v2.3.0

一、启动
适用系统：Windows 10/11，.NET Framework 4.8 或兼容的更新版本。
完整解压压缩包，双击 MakiseDesktopPet.exe。无需安装、登录或联网。
请保留 exe 旁的 assets 文件夹、dialogues.json 和配置文件。
需要移动程序时，整个文件夹一起移动；可以为 exe 创建桌面快捷方式。

二、操作
清醒待机时移动鼠标：眼珠追随指针，头部和后发轻微跟随；不推迟睡眠。
普通点击：三种表情依次循环，第二张为抱臂嘟脸。
短时间连续点击：胸前叉手抗议，停点后恢复。
按住拖动：单张完整姿态随鼠标方向连续形变，停下后回正，保留滴泪；松开保存位置。
三分钟不与桌宠互动：自动睡眠，带呼吸与动态 ZZZ。
右键角色：换一句话、通过左小右大的滑条调整角色大小（100–500 像素）、用减号/加号调整界面大小（80%–150%，默认 100% 等于旧版 120% 的实际尺寸）、置顶/置底、隐藏、退出。
任务栏右下角托盘：右键显示/隐藏和退出，双击恢复显示。
隐藏不是退出；选择“退出”才会结束进程。

三、设置与更新
位置、角色大小、界面大小、层级设置保存在：%LOCALAPPDATA%\MakiseDesktopPet\settings.json
更新前从托盘退出旧版；把新版完整解压到新文件夹后启动。
设置会继续沿用；旧桌面快捷方式需要改为指向新版。
默认不开机启动，不监控其他软件的键盘输入。

四、常见问题
没有看到角色：检查系统托盘，或收起其他窗口查看桌面（可能处于置底）。
缺少素材：重新完整解压，不要只提取 exe。
重复启动没有反应：程序只运行一个实例，请先从托盘找到已有实例。
缺少 .NET Framework：按微软官方说明安装 .NET Framework 4.8 运行时。

五、测试范围
主要在 Windows 11、150% 缩放、单显示器环境验证。
多显示器拔插、其他 Windows 电脑和长期稳定性仍需使用反馈。
