牧濑红莉栖桌宠 v2.4.0

一、启动
适用系统：Windows 10/11，.NET Framework 4.8 或兼容的更新版本。
完整解压压缩包，双击 MakiseDesktopPet.exe。基本功能无需安装 Ollama、登录或联网。
请保留 exe 旁的 assets 文件夹、dialogues.json、chat-persona.json 和配置文件。
需要移动程序时，整个文件夹一起移动；可以为 exe 创建桌面快捷方式。

二、可选的本地聊天：首次设置
1. 从 https://ollama.com/download/windows 安装并启动 Ollama for Windows。
2. 保持首次下载时联网，双击本包中的 Install-Chat-Model.cmd，等待 qwen3:4b-instruct 下载完成；模型约 2.5 GB，实际大小以下载工具显示为准。
3. 启动桌宠，右键角色或托盘图标，选择“聊两句”。输入文字后按回车发送；Shift+回车换行，Esc 关闭输入面板。回复只显示在人物气泡中。

也可以打开 PowerShell，手动执行：ollama pull qwen3:4b-instruct
Install-Chat-Model.cmd 调用同目录的 setup-chat.ps1；两者是模型下载辅助脚本，不包含模型或 Ollama。下载一次后，后续聊天只连接本机 127.0.0.1:11434，不需要持续联网、云端账号或付费 API。使用聊天时仍需启动 Ollama。
普通点击台词、动作、睡眠和托盘功能不依赖模型。首次加载模型可能较慢。

三、聊天偏好与上下文
右键角色或托盘菜单中的“聊天偏好”，可设置称呼、回复长短、感兴趣和希望避开的话题。
偏好仅保存在：%LOCALAPPDATA%\MakiseDesktopPet\chat-preferences.json
保存偏好会开始新会话；本次运行最多保留最近 12 轮，并尝试保留少量更早的明确用户事实。退出后不保存聊天记录。小模型仍可能忘记细节或答非所问。
角色口吻配置为程序旁的 chat-persona.json，修改后重启生效。

四、其他操作
清醒待机时移动鼠标：眼珠追随指针，头部和后发轻微跟随；不推迟睡眠。
普通点击：三种表情依次循环，第二张为抱臂嘟脸。
短时间连续点击：胸前叉手抗议，停点后恢复。
按住拖动：单张完整姿态随鼠标方向连续形变，停下后回正，保留滴泪；松开保存位置。
三分钟不与桌宠互动：自动睡眠，带呼吸与动态 ZZZ。
右键角色：换一句话、通过左小右大的滑条调整角色大小（100–500 像素）、用减号/加号调整界面大小（80%–150%，默认 100% 等于旧版 120% 的实际尺寸）、置顶/置底、聊天偏好、隐藏、退出。
任务栏右下角托盘：右键显示/隐藏、聊两句、聊天偏好和退出，双击恢复显示。
隐藏不是退出；选择“退出”才会结束进程。

五、设置与更新
位置、角色大小、界面大小、层级设置保存在：%LOCALAPPDATA%\MakiseDesktopPet\settings.json
更新前从托盘退出旧版；把新版完整解压到新文件夹后启动。
设置和聊天偏好会继续沿用；旧桌面快捷方式需要改为指向新版。
默认不开机启动，不监控其他软件的键盘输入。

六、常见问题
没有看到角色：检查系统托盘，或收起其他窗口查看桌面（可能处于置底）。
缺少素材：重新完整解压，不要只提取 exe。
重复启动没有反应：程序只运行一个实例，请先从托盘找到已有实例。
缺少 .NET Framework：按微软官方说明安装 .NET Framework 4.8 运行时。
聊天提示未连接：确认 Ollama 已启动；安装后如命令行找不到 ollama，关闭并重开 PowerShell。
聊天提示缺少模型：运行 Install-Chat-Model.cmd，或执行 ollama pull qwen3:4b-instruct。
回复不准确：小模型可能遗漏前文；长对话可重新明确关键事实。部分未经证实的场景描述会重试一次，必要时显示本地短句。
